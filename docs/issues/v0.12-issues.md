## [V1.0-SEC-37] Authenticate Chunked Object Completeness ✅ DONE

- Priority: P0
- Status: **✅ VERIFIED COMPLETE**
- Plan: `docs/plans/V1.0-SEC-37-plan.md`

with a fixed terminal record, preventing successful reads of truncated streams.

- [x] V1 remains readable, is classified for migration, and its limitation is documented.
- [x] Unknown versions fail closed and all size/range arithmetic is overflow checked.
- [x] ADR 0016, migration guidance, release notes, and named unit/API tests are complete.
- [x] Tier 1 and provider-agnostic Tier 2 conformance tests pass per `docs/TESTING.md`.

> **Verification**: 2026-08-19 — PASS (final independent verification, supersedes the 2026-08-18 FAIL).
> Verified by plan-verifier against `docs/plans/V1.0-SEC-37-plan.md`. All prior API metadata-expansion, short-final range, centralized arithmetic, test-contract, coverage, conformance, and isolation gaps were confirmed closed. ADR 0016 records the GET-through-gateway -> PUT-through-gateway upgrade mechanism.

## [V1.0-SEC-38] Prevent Nonce Reuse on Multipart Part Replacement ✅ DONE
- Owner: Security / Crypto / API
- Priority: P0
- Status: **✅ VERIFIED COMPLETE**
- Plan: `docs/plans/V1.0-SEC-38-plan.md`

### Summary
Encrypted multipart uploads atomically claim the first content for each part
number, permitting identical retries and rejecting changed replacements before
they can reuse a GCM nonce.

### Definition of Done

- [x] Identical retries remain byte-identical; changed content is rejected before nonce reuse.
- [x] Complete validates exactly the client-selected committed parts and ETags.
- [x] UploadPartCopy and lifecycle concurrency use the same atomic state contract.
- [x] Legacy in-flight encrypted uploads are abort-only after a coordinated rollout; completed objects remain compatible.
- [x] Tier 1 and capability-gated encrypted-MPU conformance tests pass per `docs/TESTING.md`.

> **Verification**: 2026-08-21 — PASS (supersedes the 2026-08-20 PARTIAL).
> Verified by plan-verifier against `docs/plans/V1.0-SEC-38-plan.md`. Atomic state transitions, claim-before-I/O enforcement, lifecycle handling, legacy compatibility, metrics, manifests, readiness guidance, tests, and coverage were independently verified.

- Priority: P0

- [x] Raw backend relocation fails; gateway CopyObject rebinds source plaintext to the destination.
- [x] MPU data and companion manifests share and validate an authenticated relationship identifier.
- [x] V1.0-SEC-37 framing remains unchanged and all range, copy, MPU, FIPS, and migration tests pass.
- [x] Tier 1 and capability-gated object-binding conformance tests pass per `docs/TESTING.md`.
